## 01. Executive Summary

Host internal `10.18.200.126` melakukan brute force SSH ke server `ns1` (`10.1.2.10`), berhasil login sebagai `ubuntu`, naik ke root lewat `sudo`, lalu menjalankan web server sementara di port 81 untuk mengambil `/etc/shadow` dan arsip aplikasi FileRun. Secara paralel, penyerang juga melakukan brute force ke halaman login FileRun.

Severity **Critical**: server dikuasai penuh (root), hash password semua akun lokal dicuri, dan data aplikasi diambil. Aktivitas terekam berakhir 26 Sep 2023 03:30 (-0700). Persistensi belum diperiksa.

## 04. Technical Investigation

**Attack vector:** brute force password SSH dari jaringan internal, dilanjutkan penyalahgunaan `sudo`.

**Threat actor:** tidak diketahui. Sumber adalah host internal `10.18.200.126`. Belum jelas apakah host itu milik pengguna yang menyalahgunakan akses atau host yang sudah dikuasai pihak lain.

## 08. Root Cause Analysis

Penyebab utama: **akun `ubuntu` memakai password yang bisa ditebak, dan SSH menerima login password dari jaringan internal tanpa pembatasan.**

Faktor yang memungkinkan:

- Tidak ada pembatasan percobaan login (1.700+ percobaan dalam 15 menit tidak diblokir).
- Akun `ubuntu` punya hak `sudo` penuh, sehingga satu kredensial cukup untuk root.
- Login `root` lewat SSH tidak dinonaktifkan (dicoba 1.344 kali).
- FileRun versi 2017 tanpa rate limit di halaman login.
- Tidak ada deteksi untuk port non-standar (81) yang tiba-tiba melayani file.

## 09. Recommendations

**Jangka pendek:**

1. Jalankan tindakan di bagian 06 (pending approval).
2. Forensik persistensi di `ns1`: crontab, `~/.ssh/authorized_keys`, akun baru, unit systemd, `bash_history`, file yang berubah 26 Sep 2023 03:00–04:00.
3. Periksa isi `FileRun_2017_09_18_PHP70.zip` untuk menentukan apakah ada data pengguna.

**Jangka panjang:**

1. SSH: wajib key-based, matikan login password dan `PermitRootLogin`, pasang fail2ban atau sejenisnya.
2. Batasi `sudo` hanya untuk perintah yang perlu; aktifkan `auditd` untuk mencatat perintah di shell root.
3. Upgrade FileRun; tambahkan rate limit/CAPTCHA di login.
4. Alert untuk brute force SSH dan listener baru di port non-standar (misalnya lewat Wazuh).

## 11. Lessons Learned

- **Deteksi terlambat:** insiden terjadi 2023 dan baru dianalisa 2026. Tanpa alert otomatis, brute force 1.700+ percobaan tidak memicu respons.
- **Bukti tanpa catatan custody:** pengumpul awal dan hash saat pengumpulan tidak tercatat. Ke depan, hash dihitung saat bukti diterima, sebelum rename atau pemindahan.
- **Celah pencatatan:** perintah di dalam shell root (`su`) tidak tercatat, sehingga mekanisme pengambilan `/shadow` pukul 03:25 (sebelum `http.server` tercatat di sudo log pukul 03:29) hanya bisa dihipotesiskan.
- **Tooling:** analisa otomatis lewat Hermes akurat, tapi sebagian besar berasal dari model, bukan tool WOLFSTRIKE. Detail evaluasi di [laporan tes](../testing/INC-002.md).
